# SpaceLab Research — Field Notes

Source of the SpaceLab Research editorial website.

## Edit the homepage

Open `app/page.tsx`, click the pencil icon, modify the text, then choose
**Commit changes**. GitHub Pages republishes the site automatically.

## Edit an article

The current articles are in:

- `app/notes/p300-quality-change/page.tsx`
- `app/notes/wearable-habitat-interface/page.tsx`
- `app/notes/event-synchronisation/page.tsx`

## Add images or papers

- Images: `public/images/`
- Papers: create `public/papers/`, then upload PDF files there

The public test address is <https://spacelabresearch.github.io/>. The custom
domain `spacelabresearch.com` is intentionally not connected.

## Preview on a computer

```bash
npm install
npm run dev
```
